# Кошелёк студента: учёт личных расходов

## 1. Краткое описание

Студенту сложно понять, сколько он тратит за месяц и на что уходит бóльшая часть денег. Записи в заметках и подсчёт вручную не дают быстрого итога.

«Кошелёк студента» — это веб-приложение для студентов. Пользователь вносит траты с суммой, категорией и датой. Приложение сразу показывает общий итог за выбранный месяц и суммы по категориям. Записи хранятся в браузере и не пропадают после обновления страницы.

## 2. Что реализовано

### Добавление расхода

Форма содержит четыре поля:

| Поле | Обязательное | Правила проверки |
|---|---|---|
| Сумма, ₸ | да | Больше нуля, до 2 знаков после запятой, максимум 100 000 000 ₸. Можно писать `1 500` или `350,50`. |
| Категория | да | Одна из 9: Еда, Транспорт, Жильё, Учёба, Связь и интернет, Развлечения, Здоровье, Одежда, Другое. |
| Дата | да | Реальная календарная дата с 2000 по 2100 год. По умолчанию стоит сегодняшняя. |
| Описание | нет | До 120 символов. |

Неверные данные не сохраняются. Под каждым ошибочным полем появляется понятное сообщение, например «Сумма должна быть больше нуля.» или «Выберите категорию.».

### Список расходов

- Показываются все записи за выбранный месяц: свежие даты сверху.
- У каждой записи видны категория, дата, сумма и описание (если оно есть).
- Запись удаляется кнопкой ✕. Удаление можно отменить кнопкой «Отменить» в течение 6 секунд.
- Для месяца без записей показывается пустое состояние «Пока пусто».

### Итоги за месяц

- Общая сумма, число записей и число категорий.
- Суммы по категориям с долей в процентах, от большей к меньшей.
- Цветная полоса, которая показывает структуру расходов.
- Строка проверки «✓ Сумма категорий = итог».
- Итоги пересчитываются при добавлении, удалении и смене месяца.

### Выбор месяца

- Месяц выбирается через поле месяца или стрелками ‹ ›.
- Если добавить расход с датой из другого месяца, приложение переключится на этот месяц и сообщит об этом.

### Сохранение и надёжность

- Записи сохраняются в `localStorage` браузера и остаются после обновления страницы.
- При загрузке каждая запись проверяется. Повреждённые записи пропускаются, а пользователь видит предупреждение.
- Если браузер запрещает сохранение, например в приватном режиме, показывается предупреждение.
- Изменения, сделанные в другой вкладке, подтягиваются автоматически (через событие `storage`).
- Все суммы учитываются в одной валюте, тенге (₸), без конвертации.

### Интерфейс

- Адаптивная вёрстка: на узком экране блоки встают в одну колонку.
- У полей есть подписи и атрибут `aria-invalid`, кнопки доступны с клавиатуры.
- При включённой в системе настройке «уменьшить движение» анимации отключаются.

## 3. Как работает решение

1. Пользователь открывает приложение. Показывается текущий месяц, а записи загружаются из `localStorage`.
2. Пользователь заполняет форму (например, сумма `1500`, категория «Еда», дата) и нажимает «Добавить расход».
3. Данные проверяются. При ошибке под полем появляется сообщение, и запись не создаётся.
4. Корректная запись добавляется в список и сохраняется в `localStorage`.
5. Итоги пересчитываются по записям выбранного месяца: общий итог, суммы по категориям и доли.
6. Пользователь может удалить запись или сменить месяц, итоги пересчитаются сразу.
7. После обновления страницы данные на месте.

## 5. Архитектура проекта

```
index.html            разметка страницы: форма, итоги, список, уведомление об удалении
css/styles.css        стили и адаптивная вёрстка
js/logic.js           чистая логика без DOM: проверка ввода, фильтр по месяцу, подсчёт итогов, форматирование
js/storage.js         чтение и запись localStorage с обработкой ошибок
js/app.js             интерфейс: состояние, отрисовка, обработчики формы, удаления, отмены и смены месяца
tests/logic.test.js   unit-тесты для js/logic.js
package.json          команды npm test и npm start
```

Как компоненты связаны:

```
       ввод пользователя
              │
              ▼
┌───────────────────────────┐  проверка, итоги   ┌───────────────────────────┐
│ js/app.js                 │ ─────────────────▶ │ js/logic.js               │
│ (интерфейс и состояние)   │ ◀───────────────── │ (чистые функции)          │
└───────────────────────────┘                    └───────────────────────────┘
              │                                                ▲
              │ load / save                                    │ проверка записей
              ▼                                                │
┌───────────────────────────┐                                  │
│ js/storage.js             │ ─────────────────────────────────┘
│ (localStorage)            │
└───────────────────────────┘
```

Ключевые решения:

- **Суммы хранятся в тиынах**, целыми числами (1 ₸ = 100 тиын). Поэтому нет ошибок округления дробных чисел, и сумма категорий всегда точно равна общему итогу.
- **Логика отделена от интерфейса.** `js/logic.js` подключается в браузере как `window.ExpenseLogic` и в Node.js через `require`, поэтому расчёты проверяются тестами без браузера.
- **Состояние не изменяется на месте.** Добавление и удаление возвращают новый массив, после чего экран перерисовывается.
- **Защита от XSS.** Пользовательский текст выводится только через `textContent`.

Формат записи в `localStorage` (ключ `student-expenses:v1`):

```json
[
  {
    "id": "7b1c3e0a-…",
    "amount": 150000,
    "category": "food",
    "date": "2026-09-15",
    "description": "Обед в столовой",
    "createdAt": 1789999999999
  }
]
```

Поле `amount` хранится в тиынах: `150000` = 1 500 ₸.

## 6. Установка и запуск

Установка не нужна: у проекта нет зависимостей и сборки.

### 1. Скачать репозиторий

```bash
git clone https://github.com/BAITC-Hacks/hack-69b6e42b-team.git
cd hack-69b6e42b-team
```

### 2. Запустить приложение

**Вариант А.** Откройте `index.html` в браузере двойным кликом.

**Вариант Б, через локальный сервер** (нужен Node.js):

```bash
npm start
```

Команда запускает `npx --yes serve -l 5173 .`: при первом запуске npm скачает пакет `serve`. После этого откройте http://localhost:5173.

### 3. Запустить тесты

Нужен Node.js, проверено на версии 24.

```bash
npm test
```

Ожидаемый результат: `tests 13`, `pass 13`, `fail 0`.

## 7. Как проверить решение

Сценарий повторяет проверочный пример из ТЗ.

1. Откройте приложение. Если в браузере остались старые записи, удалите их кнопкой ✕.
2. Добавьте три расхода с датой из одного месяца:

   | Сумма | Категория |
   |---|---|
   | 1500 | Еда |
   | 600 | Транспорт |
   | 900 | Еда |

   Ожидается: **Всего 3 000 ₸**, Еда — 2 400 ₸, Транспорт — 600 ₸. Внизу строка «✓ Сумма категорий = итог (3 000 ₸)».
3. Удалите расход «Еда, 900 ₸».
   Ожидается: **Всего 2 100 ₸**, Еда — 1 500 ₸, Транспорт — 600 ₸.
4. Обновите страницу (F5). Записи и итоги на месте.
5. Нажмите ‹, чтобы перейти на предыдущий месяц. Итог 0 ₸ и пустой список. Нажмите ›, чтобы вернуться.
6. Проверьте отклонение неверных данных:
   - сумма `-100` или `0`: «Сумма должна быть больше нуля.»;
   - сумма `abc`: сообщение о неверном формате числа;
   - без категории: «Выберите категорию.».

   Запись в этих случаях не добавляется.

Шаги 2–3 также проверяются автоматически тестом «проверочный пример из ТЗ (раздел 7)» в `tests/logic.test.js`. Остальные тесты проверяют:

- проверку суммы и даты;
- фильтр по месяцу;
- пустой список;
- сортировку;
- равенство суммы категорий итогу;
- обработку повреждённых данных.

## 8. Данные и интеграции

- **Источник данных.** Только то, что пользователь вводит вручную. Заранее подготовленных данных и итогов нет, все расчёты идут по введённым записям.
- **Хранение.** `localStorage` текущего браузера. Сервера и базы данных нет.
- **Внешние API и сервисы.** Не используются. Единственный внешний запрос — загрузка шрифта Manrope с Google Fonts. Без интернета приложение работает с системным шрифтом.
- **Команда `npm start`.** Скачивает пакет `serve` через npx. Для запуска через `index.html` и для `npm test` это не нужно.

## 9. Ограничения

- Данные хранятся только в текущем браузере на текущем устройстве.
  - Нет регистрации, синхронизации между устройствами и резервного копирования.
  - Очистка данных сайта удаляет все записи.
- Одна валюта (₸), без конвертации.
- Список категорий фиксированный (9 штук), свои категории добавить нельзя.
- Записи нельзя редактировать: только удалить и добавить заново.
- Нет месячного бюджета, отдельного графика и экспорта данных.
- Сумма — от 0,01 до 100 000 000 ₸, даты — с 2000 по 2100 год.
- Нужен современный браузер: используются CSS `color-mix()` и `Element.replaceChildren()`.
- Основной сценарий проверялся в Chromium-браузере через локальный сервер. В других браузерах и при открытии файла напрямую (`file://`) отдельного тестирования не было.
- Автотестами покрыта логика расчётов (`js/logic.js`). Интерфейс проверялся вручную, автоматических E2E-тестов нет.
