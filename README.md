# Кошелёк студента: учёт личных расходов

Прототип для хакатона по ТЗ «Учёт личных расходов студента». Это веб-приложение на чистом HTML, CSS и JavaScript. Оно работает без сервера, сборки, регистрации и внешних API.

## Запуск

**Способ 1, самый простой.** Откройте файл `index.html` двойным кликом в браузере (Chrome, Edge, Firefox).

**Способ 2, через локальный сервер** (нужен Node.js):

```bash
npx serve -l 5173 .
```

После этого откройте http://localhost:5173.

**Тесты логики расчёта** (Node.js 18+, зависимости не нужны):

```bash
npm test
```

## Реализованные функции

Обязательный сценарий по ТЗ:

- **Форма расхода.** Поля: сумма, категория, дата и необязательное описание.
  - Сумма должна быть положительной. Можно писать с пробелами (`1 500`) и с запятой (`350,50`), не больше 2 знаков после запятой.
  - Неверные данные отклоняются. Под каждым полем появляется понятное сообщение.
- **Список расходов за выбранный месяц.** Свежие записи сверху. Каждую запись можно удалить, удаление можно отменить в течение 6 секунд.
- **Итоги за месяц.** Показываются общая сумма и суммы по категориям (с долей в процентах). Итоги пересчитываются при добавлении, удалении и смене месяца.
- **Проверка «сумма категорий = итог».** Выводится прямо в интерфейсе.
- **Выбор месяца.** Через поле месяца или стрелками ‹ ›. Если добавить расход с датой из другого месяца, приложение переключится на этот месяц и сообщит об этом.
- **Сохранение в браузере** (`localStorage`). Записи остаются после обновления страницы.
- **Пустые состояния.** Если в месяце нет записей, это понятно показано.

Дополнительно:

- Цветная полоса структуры расходов.
- Синхронизация между открытыми вкладками.
- Адаптивная вёрстка под телефон.
- Доступность: подписи полей, `aria-invalid`, навигация с клавиатуры.

## Проверочный пример (раздел 7 ТЗ)

1. Добавьте три расхода в одном месяце: Еда 1500, Транспорт 600, Еда 900.
   Ожидается: **всего 3 000 ₸**, Еда 2 400 ₸, Транспорт 600 ₸.
2. Удалите расход на 900.
   Ожидается: **всего 2 100 ₸**, Еда 1 500 ₸.

Этот сценарий автоматически проверяется тестом в `tests/logic.test.js`.

## Как устроено

```
index.html          разметка
css/styles.css      стили
js/logic.js         чистая логика: валидация, фильтр по месяцу, итоги (без DOM, покрыта тестами)
js/storage.js       чтение и запись localStorage с обработкой ошибок
js/app.js           интерфейс: форма, список, итоги, удаление с отменой
tests/logic.test.js unit-тесты (node:test)
```

**Точность расчёта.** Суммы хранятся в тиынах, целыми числами (1 ₸ = 100 тиын). Поэтому ошибок округления дробных чисел нет, и сумма по категориям всегда точно равна общему итогу.

**Надёжность.**
- Данные из `localStorage` проверяются при загрузке, повреждённые записи пропускаются.
- Если хранилище недоступно (например, в приватном режиме), показывается предупреждение.
- Пользовательский текст выводится только через `textContent`, это защита от XSS.

## Ограничения

- Одна валюта: тенге (₸), без конвертации.
- Данные хранятся только в текущем браузере на текущем устройстве. Нет регистрации, синхронизации между устройствами и резервного копирования. Очистка данных сайта удаляет записи.
- Категории фиксированные (9 штук), свои категории добавить нельзя.
- Сумма от 0,01 до 100 000 000 ₸. Даты с 2000 по 2100 год.
- Редактирования записи нет: запись можно удалить и добавить заново.
- Шрифт Manrope загружается из Google Fonts. Без интернета используется системный шрифт, на работу это не влияет.
